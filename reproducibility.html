Reproducibility

Overview

This page explains how to restore the software environments, rebuild the reference dataset, run the applications and their tests, and deploy them. All commands are run from the folder shown.

R application (Shiny_app/R)

Restore the environment

Package versions are locked in renv.lock:

Rscript -e "renv::restore()"

On a new machine you can instead install everything and write a new lockfile with:

Rscript 00_setup.R

Build the reference dataset

Rscript 01_data_prep.R

This downloads GSE60450 from GEO, runs limma-voom and writes data/GSE60450_limma.csv for both applications. It takes about two minutes on a laptop.

Run and test

Rscript -e "shiny::runApp()"
Rscript tests/testthat.R

Python application (Shiny_app/python)

Restore the environment

conda env create -f shiny_app_py_env.yml
conda activate shiny_app_py

or, without conda:

python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt

Run and test

shiny run app.py
pytest -q

Continuous integration and releases

Every push runs a version check, linting (lintr, ruff) and both test suites on GitHub Actions (.github/workflows/ci.yml). Pushing a version tag such as v1.0.0 runs the release workflow: it repeats these checks, publishes Docker images of both applications to GitHub Container Registry, creates a GitHub Release from CHANGELOG.md, and redeploys both applications. Each release can be archived on Zenodo with its own DOI.

Troubleshooting

The uploaded file is rejected

The message names the missing or invalid column. Column names are case-sensitive: gene, logFC and adj.P.Val are required.

Python GO enrichment does not run

The Python application queries the Enrichr web service, so the server must have internet access. The other tabs and the download still work, and the report records that enrichment could not be run.

Results differ between R and Python

The two applications illustrate the same design principles with different libraries. GO term lists differ because the annotation sources differ (org.Mm.eg.db versus Enrichr). For the genomics example in the manuscript, the R application is the reference implementation.
