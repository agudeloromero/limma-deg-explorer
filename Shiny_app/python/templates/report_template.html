Methods

Differentially expressed genes (DEGs) were taken from a limma results table (Ritchie et al. 2015) and selected using Benjamini–Hochberg adjusted P-value ≤ {{ deg_pval }} and |log₂FC| ≥ {{ deg_lfc }}.

Gene Ontology over-representation analysis was run with gseapy {{ versions.gseapy }} (Fang et al. 2023) through the Enrichr web service (Chen et al. 2013; libraries: {{ go_libraries }}). All {{ n_total }} genes in the input table were used as the background set. Gene symbols were matched case-insensitively to the Enrichr libraries. Terms with adjusted P-value ≤ {{ enr_pval }} are reported.

The R implementation of this application uses clusterProfiler with the offline org.Mm.eg.db annotation instead, so term lists can differ between the two versions.
